# Responsible Use

EL-VERIFY is intended to support investigation and media literacy, not to make unreviewable accusations.

- Never describe a person or account as fake solely because a model flags it.
- Do not use face recognition or infer a person's identity from an image.
- Distinguish verified facts, technical indicators, user-provided claims, and unknowns.
- Provide sources and explain confidence limitations.
- Respect platform terms, privacy, copyright, and applicable law.
- Do not bypass authentication, access controls, rate limits, or private account settings.
- Minimize data collection and retention.
- Provide a way to correct or challenge an erroneous report.
