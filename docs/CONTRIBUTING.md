# Contributing

EL-VERIFY is at an early stage. Contributions should be small, documented, and testable.

1. Open an issue describing the problem or proposed change.
2. Explain security, privacy, and false-positive implications.
3. Add tests for new behavior.
4. Document limitations and data sources.
5. Submit a pull request.

Do not submit private personal data, scraped private content, credentials, or datasets without clear permission and licensing.
